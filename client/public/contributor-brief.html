ARCOLYTE TECHNOLOGIES Open Source Brief

Contributor Project Brief

This brief is for external contributors who want a predictable understanding of the ARCOLYTE TECHNOLOGIES codebase before forking. It complements the in-app docs route at /doc and can be printed to PDF directly from the browser.

Stack

  • Frontend: React 18, TypeScript, Vite, Tailwind, Radix UI
  • Backend: Node.js, Express, TypeScript
  • Database: MongoDB Atlas via Mongoose
  • Testing: TypeScript checks and Playwright E2E

Required Local Setup

npm install
npm run dev
npm run check
npx playwright install chromium
npm run test:e2e

MONGODB_URI is required. The project now runs Atlas-only and fails fast if the URI is missing.

Important Backend Entry Points

  • server/routes.ts: API routes and EmailOS endpoints
  • server/emailLeadAggregator.ts: business lead aggregation logic and fallbacks
  • server/index.ts: server boot and middleware wiring
  • server/env.ts: runtime environment validation
  • server/mongodb.ts: Atlas connection and startup requirements

Recently Shipped Changes

  • EmailOS aggregation moved from Python subprocess logic to JavaScript-native server code.
  • Local/in-memory MongoDB fallback was removed; Atlas is mandatory.
  • Global motion was reduced to improve responsiveness.
  • Playwright E2E coverage was added for EmailOS fetch-leads flow.
  • Business lead requests are no longer limited by the old 500-request cap.

Good First Issues

  • Add focused Playwright coverage around auth redirects and onboarding edge cases.
  • Improve docs for environment setup and deployment caveats.
  • Reduce bundle size with route-level chunking.
  • Add backend tests for aggregation dedupe and limit behavior.
